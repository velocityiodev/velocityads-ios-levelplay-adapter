# Changelog

## [0.11.0.0] - 2026-10-07

### Added

* Initial release of the Velocity Ads Unity LevelPlay custom adapter for iOS.
* Supports interstitial, rewarded, banner, large banner, MREC, leaderboard,
  smart, adaptive, and custom banner requests.
* Wraps Velocity Ads iOS SDK 0.11.x.
* Supports Unity LevelPlay SDK 9.6.x.
* Forwards GDPR consent and CCPA Do Not Sell signals.
* Requires iOS 15.0 or later.
